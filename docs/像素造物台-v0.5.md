# 像素造物台 v0.5

2026-11-16。参考本机 3D 造物台 0.24.18 的工作区组织与引导设计，重构像素工作台的默认入口；原有角色工程与编辑能力保留。

## 用女骑士试玩

在创作页点「先拿女骑士样板试试手」，即可打开包含八个动作的独立样板工程。选择动作即可预览，也可以微调并打包。样板由仓库提供，可以离线练习。

## 八步动作制作

创作页按 **待机 → 奔跑 → 闪身 → 连段 → 蓄力 → 跳跃 → 受击 → 倒地** 管理同一个角色工程。

- **逐步制作**。新建角色后，从待机开始。有角色图就上传，只有文字也可以写进修改要求。已有待机 GIF 时，可以直接导入整段动画，或从工程里选择现有待机。生成结果可以直接播放，重新生成的候选可以通过版本选择框比较。点「打开微调」调整节奏、整帧位置和停留时长。待机定稿时选一个清楚的母版帧。采用版本后进入下一步。
- **托管模式**。上传一张角色参考图后开始。托管服务依次根据角色和装备生成八段动作，每段先生成候选并预览，再自动采用。可以暂停后比较版本、微调或添加修改要求重做，再继续。空帧、跨格、裁切或生成失败会停在当前步骤。托管在本机服务运行，关闭页面后可以重新打开查看；本机服务退出时暂停，重启后按状态继续或重新生成中断动作。
- **导出**。逐步制作完成后点「打包完整素材」。托管完成后自动准备 ZIP。包中包含八段动作的透明 PNG、图集、GIF 和时序配置。自动检查覆盖图表和资源规格，角色观感和动作手感仍需播放复核。

下游动作沿用待机定稿母版。更新母版外观后，下游步骤回到待确认状态，工程里原有动作仍可打开比较。GIF 导入保留帧时长，并合并连续相同帧，最多 64 个可编辑帧。

## 自定义动作

打开右上角「角色工程」，在动作列表上方点「新增自定义动作」，填写名称后会生成一个待制作动作。点该动作的「制作」进入创作向导，动作过程与力度可自由改写；生成结果确认切帧后，点「保存到角色」即转为正式动作。也可以先导入图表，再在动作槽选择自定义动作并保存当前时间轴。

动作列表支持上移、下移、复制和删除。删除需要原地二次确认；待机母版来源动作不能删除。一个工程最多保存 16 个动作，列表顺序会写入工程 JSON 并决定整套导出顺序。尚未制作的草稿动作会保留在工程备份中，但不会参与色板冻结和资源导出。

「新建角色」弹窗可直接使用七方向弓箭手模板。模板创建后显示自有动作列表，不再进入固定八步生产面板。模板内置待机、行走与右、左、左上、右上、顶上、左下、右下七个射击草稿，预填无箭袋、高频射击和满弓圆弧抖动规则。模板不包含最终像素美术；先制作并定稿待机母版，再生成行走与七个射击方向。8 帧中 04 为满弓基准，05/06 为反向抖动，07 松弦，08 回预备；普通射击跳过 05/06，持续满弓时在 04→05↔06 循环。

## 作品、参考库与交付

- **作品**：搜索角色工程与生成结果。工程可以打开或复制为独立副本；生成结果可以确认排版后进入编辑。
- **更多 → 参考库**：收藏图与生成图可设为本次参考；导入角色参考会沿用本地参考库。已有女骑士动作示例可以直接练习，跳过生图。类型卡片使用已有本机角色图片作造型示意，不表示一键换皮结果。
- **更多 → 交付检查**：分别检查人物、装备、动作、裁切、锚点时长、游戏内行为。勾选按角色工程内容或当前素材区分，仅表示用户手动确认。
- **动作编辑**：默认简易模式，只显示预览、动作小图、动作选择和三步操作。原有参数集中在「精细调整」，可以随时切换回来。

## 简易动作编辑

1. 先看一遍：点击小图上方播放按钮，或选中某张小图查看。已有角色工程可以从右侧下拉框切换动作。
2. 调快慢：「慢一点」把打开时各帧时长调整为约1.3倍；「快一点」约0.8倍；「原来的节奏」恢复本次打开动作时的时长。这些调整会进入实际保存与导出，重复点击同一档不会不断叠乘。毫秒按GIF所需的10ms取整。
3. 某张图需要停久一点：展开「某个姿势想多停一下？」，先选小图，再选择一闪而过（80ms）、正常停留（150ms）、多停一下（250ms）。只影响选中的一张。
4. 跳位：展开「角色突然跳了一下？」，打开脚下参考线，用箭头每次平移完整姿势1px，只影响当前帧。参考线不是自动脚底识别，正常屈膝和腾空应保留。「撤销上一次调整」可回退最近一次快慢、停留或位置操作；切换动作后不保留这次临时撤销。
5. 点「制作并下载GIF」直接开始整理真实资源，完成后下载透明GIF或素材ZIP。「保存可继续修改的文件」在角色工程下下载整套工程JSON，独立动作下载单动作项目JSON。

切换「精细调整」后，可继续使用切帧、坐标、采样倍率、锚点、色板、叠影及完整帧替换。返回简易模式时，以此刻时长作为新的节奏起点，并将临时预览倍速恢复到1倍，让观看与导出的实际时长一致。

预览会基于整组姿势的共同范围放大角色，不逐帧各自居中或缩放；这仅改变查看大小，不改导出像素和锚点。单帧素材会说明尚未构成连续动作，导出GIF也不会自动补动作。

交付页可导出当前动作GIF/资源包、整套角色资源及可编辑工程。游戏中的移动、攻击范围、伤害、事件和引擎适配仍由游戏代码处理。勾选清单不会把服务导出中的pending审核自动变为通过。

## 范围与限制

这次没有改动3D造物台源码、DSH账号凭据、Codex全局配置，也没有提交新的生图请求。原生生图通道沿用已有实现；界面验证用模拟任务检查提交文本、错误与结果流程，不等于新模型生成质量验证。

女骑士样板由仓库提供。本机额外类型参考图、角色源图和用户工程继续保存在被 Git 忽略的 `work/` 目录。
