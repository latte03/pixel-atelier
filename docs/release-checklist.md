# 对外发布检查

此文档记录公开发布前的步骤；本地项目准备完成不代表已经上传GitHub或建立远端。

## 当前已准备

- 工作流、配置、提示词与验收模板。
- PythonCLI及几何校准演示。
- 本地构建、编辑器、生成协议、角色工程与托管回归测试。
- 女骑士八段动作样板及制作复盘。
- 代码/文档MIT许可证、贡献说明、版本记录。
- 发布范围包含代码、文档和女骑士样板。个人工程、生成缓存、原游戏源码和录屏留在本机。

## 发布者最后确认

- 目标账号/组织、仓库名、公开范围与维护者联系入口。
- 接受本项目采用的MIT许可；第三方内容另附适用许可。
- 本次压缩包/仓库中不包含用户名绝对路径、密钥、缓存、work/、虚拟环境和其他项目文件。
- 在干净解压目录运行快速开始、回归测试与演示，检查预览页。
- 新增示例素材与录屏时记录来源、授权及预期用途。
- 首次发布标记为0.1.0；说明它是一套带工具的流程草案，尚无跨角色量产指标。
