# 金发双手巨剑女骑士

这是 Pixel Atelier 项目制作并随仓库发布的演示素材，用于试玩和复现整身逐帧工作流。素材来自该项目的女骑士制作过程，经过生成、动作筛选、整帧对齐和透明像素整理。本目录提供整理后的图集、各动作代表帧、演示 GIF 和播放配置。素材来源和返工过程见[女骑士案例复盘](../knight-retrospective.md)。

| 动作 | 关键姿势 | 时长 |
| --- | ---: | ---: |
| 待机 | 8 | 1320 ms |
| 奔跑 | 8 | 640 ms |
| 冲刺闪身 | 8 | 660 ms |
| 轻攻击连段 | 16 | 1640 ms |
| 蓄力重攻击 | 16 | 2100 ms |
| 跳跃 | 8 | 920 ms |
| 受击 | 8 | 760 ms |
| 被击倒 | 8 | 1400 ms |

`manifest.json` 记录每个图集的源格、锚点与帧时长。工作台复制样板时统一画布和锚点，保留原生像素尺度。示例图集包含每帧已经绘制的刀光。图集和 GIF 用于演示动作与导出，碰撞、判定与角色位移需在游戏中配置。

本目录的示例美术随项目提供作演示与复现。仓库的 MIT 许可条款适用于代码和文档。
